# Thực hành CSS grid-gap

Mở `index.html` bằng trình duyệt để xem cả hai ví dụ:

1. Lưới 2 cột, 4 ô: `grid-gap: 20px`.
2. Lưới 3 cột, 6 ô: `grid-gap: 30px 10px`.

Các quy tắc nằm trong `style.css`.

## Ảnh nộp bài

- `example-1.png`: kết quả ví dụ 1.
- `example-2.png`: kết quả ví dụ 2.
- `grid-gap-preview.png`: toàn bộ trang.

Trong Developer Tools, kiểm tra `row-gap` và `column-gap` ở tab Computed.
